# CodeAlpha - Basic Chatbot (Python)

## Internship Task
This project was built as part of the CodeAlpha Python Programming Internship — Task 1: Basic Chatbot.

## Description
A simple rule-based chatbot built in Python that runs in the console. The chatbot takes user input, matches it against predefined keywords and phrases, and responds with an appropriate reply.

## Features
- Responds to greetings like "hello", "hi", "hey"
- Answers questions like "how are you" and "what is your name"
- Provides a help menu when the user types "help"
- Exits when the user types "bye", "goodbye", "exit", or "quit"
- Gives a fallback response for unrecognized input

## Key Concepts Used
- if-elif conditional logic
- Functions
- Loops (while)
- Input/output handling

## How to Run
1. Make sure Python 3 is installed.
2. Download chatbot.py
3. Run: python3 chatbot.py
4. Type 'help' to see commands, or 'bye' to exit.
